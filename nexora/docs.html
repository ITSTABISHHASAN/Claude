Get Started

[ Documentation · v4.0 ]

Ship your first agent in five minutes.

Install the CLI, connect a system and describe the outcome you want. The agent drafts the workflow; you approve it.

Terminal
npm install -g @nexora/cli
nexora login
nexora connect ledger crm
nexora agents create "Reconcile open invoices every morning"
# ✓ Workflow drafted · 6 steps · awaiting approval
